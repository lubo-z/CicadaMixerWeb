# 产品需求

## 1. 产品目标

CicadaMixer Web 是一个用浏览器运行的蝉鸣氛围播放器。用户可以手动混合多种蝉鸣，也可以按季节、月份和一天中的时间生成合理的播放组合。

首版目标是复现原 CicadaMixer 的可见功能，不把结果描述为真实生态预测。实际鸣叫还会受地点、天气、温度、海拔和个体差异影响。

## 2. 首版范围

首版包含：

- 单页 Web 界面；
- 手动混音；
- 时节自动选择；
- 实时自动更新；
- 17 种现有蝉鸣的循环播放；
- 媒体和配置由后端提供；
- 个别媒体失败时继续播放其余音轨；
- 桌面和移动端现代浏览器的响应式界面；
- 可通过配置增加、删除或调整蝉种及时间段。

首版不包含：

- 用户账户、云同步或播放历史；
- 上传媒体或在线配置后台；
- 服务端音频混音、录制或下载混音结果；
- 视频画面；
- 根据地理位置、天气或传感器进行生态预测；
- 多用户实时协作。

## 3. 功能需求

### PR-MAN：手动混音

- **PR-MAN-001** 用户可切换到“手动混音”模式。
- **PR-MAN-002** 用户可勾选一个或多个启用且媒体可用的蝉种。
- **PR-MAN-003** 点击“播放”后，以候选选择整体替换活动组合，并让全部活动音轨循环播放。
- **PR-MAN-004** 播放期间改变勾选状态只改变候选选择，不立刻改变活动组合；再次点击“播放”才应用。
- **PR-MAN-005** 未选择任何蝉时点击“播放”，不改变当前播放状态，并显示明确提示。
- **PR-MAN-006** 点击“停止”后停止并释放所有活动音轨，状态变为“已停止”。
- **PR-MAN-007** 手动模式提供“清空已选”按钮；点击后只清空候选选择，不停止、替换或重启当前活动组合。

### PR-AUTO：时节自动

- **PR-AUTO-001** 用户可切换到“时节自动”模式。
- **PR-AUTO-002** 时节选项为当前月份、春季（3–5 月）、夏季（6–8 月）、秋季（9–11 月）、冬季（12、1、2 月）。
- **PR-AUTO-003** “当前月份”取浏览器本地日期。
- **PR-AUTO-004** 季节模式采用月份集合重叠语义：蝉种活跃月份与季节月份有至少一个交集即可通过月份过滤，不表示它整个季节都出现。
- **PR-AUTO-005** 每日时段选项为实时、黎明、上午、午后、黄昏、夜间和自定义时间。
- **PR-AUTO-006** 固定每日时段默认边界为：黎明 `[05:00, 07:30)`、上午 `[07:30, 12:00)`、午后 `[12:00, 16:30)`、黄昏 `[16:30, 19:00)`、夜间 `[19:00, 24:00) ∪ [00:00, 05:00)`。
- **PR-AUTO-007** “实时”取浏览器本地时间；自定义时间接受合法的 24 小时制 `HH:MM`。
- **PR-AUTO-008** 自动模式下蝉种列表展示计算结果，但不可手动勾选。
- **PR-AUTO-009** 自动组合只包含允许自动播放、配置完整且媒体启用的蝉种；组合上限使用当前浏览器设置，默认 6 种，且必须处于后端目录声明的允许范围内（首版 1–10）。
- **PR-AUTO-010** 点击“播放”时重新计算并整体应用自动组合。
- **PR-AUTO-011** 没有匹配项时不开始声音，并显示“当前没有匹配的蝉种”。
- **PR-AUTO-012** 自动结果必须可复现：相同目录配置、月份选择和时间输入得到相同结果。

### PR-LIVE：实时自动更新

- **PR-LIVE-001** 自动更新只在“时节自动 + 实时”中可启用，默认启用。
- **PR-LIVE-002** 用户必须先点击一次“播放”以满足浏览器手势要求并启动自动会话。
- **PR-LIVE-003** 检查间隔使用当前浏览器设置，默认 30 分钟；首版允许 5–120 分钟并以 5 分钟递增。检查点按该间隔与浏览器本地墙上时钟对齐。
- **PR-LIVE-004** 状态区域显示下一个检查时间。
- **PR-LIVE-005** 检查所得组合与活动组合相同时不中断声音。
- **PR-LIVE-006** 组合变化时，用新组合替换活动组合。
- **PR-LIVE-007** 没有匹配项时暂停声音但保持自动会话；后续检查重新出现匹配项时自动恢复。
- **PR-LIVE-008** 停止、切换到手动模式、离开实时、关闭自动更新或页面关闭，都会取消自动会话和计时器。
- **PR-LIVE-009** 页面进入后台后浏览器可能节流计时器；页面恢复可见时立即补做一次检查，并重新对齐下一检查点。
- **PR-LIVE-010** 自动会话运行期间修改检查间隔时，不中断活动声音；系统取消旧计时器，并按新间隔重新计算下一检查点。

### PR-PREF：浏览器级用户设置

- **PR-PREF-001** 自动混音上限和实时检查间隔是浏览器级用户设置，不写回后端配置，也不影响其他浏览器或用户。
- **PR-PREF-002** 后端配置只声明每项设置的默认值、最小值、最大值和必要步长；前端不能提供超出这些约束的选项。
- **PR-PREF-003** 设置保存在浏览器 `localStorage`；页面刷新或重开后在同一源下恢复。清除网站数据或更换浏览器后恢复后端默认值。
- **PR-PREF-004** 前端加载设置时必须按最新 Catalog 约束重新校验；缺失、格式错误、越界或不符合步长的值逐项恢复默认值，并用规范值覆盖无效存储。
- **PR-PREF-005** 修改自动混音上限后立即重算预览组合，但不改变活动组合；再次点击“播放”或实时检查时才应用。
- **PR-PREF-006** 首版不提供账户同步、服务端保存设置或修改运行时配置的 API。

### PR-MEDIA：媒体播放与容错

- **PR-MEDIA-001** 每个音轨独立循环，只输出音频，不展示视频画面。
- **PR-MEDIA-002** 播放前显示“正在准备音轨”。
- **PR-MEDIA-003** 单个媒体加载或解码失败不应阻止其他可用媒体播放。
- **PR-MEDIA-004** 状态区域显示成功播放数量及失败的蝉种。
- **PR-MEDIA-005** 所有选中媒体均失败时显示错误状态，不声称正在播放。
- **PR-MEDIA-006** 后端必须支持浏览器按字节范围请求媒体。
- **PR-MEDIA-007** 每种蝉使用配置中的默认音量；首版不要求用户单独调节音量。

### PR-CAT：目录和配置

- **PR-CAT-001** 界面展示中文名和学名；悬停或聚焦后展示资料说明及媒体文件名。
- **PR-CAT-002** 配置可管理蝉种 ID、名称、学名、媒体、月份、峰值月份、鸣叫时段、资料可靠度与说明、来源、默认音量、排序、启用状态和自动播放资格。
- **PR-CAT-003** 媒体文件名允许空格、中文及 Unicode 字符；API 和 URL 必须正确编码。
- **PR-CAT-004** 配置由后端启动时校验；无效配置不得静默进入目录。
- **PR-CAT-005** 配置或资源变更后重启后端生效，首版不要求热更新。
- **PR-CAT-006** Catalog 必须向前端提供自动混音上限和实时检查间隔的默认值及允许范围；配置须满足 `min <= default <= max`，检查间隔还须满足步长约束。

### PR-STATUS：状态与可访问性

- **PR-STATUS-001** 状态区至少覆盖：已停止、正在准备、正在播放、没有匹配项、部分/全部媒体失败、下一次更新时间。
- **PR-STATUS-002** 关键操作可用键盘完成，提示信息不能只靠颜色表达。
- **PR-STATUS-003** 状态变化使用适当的 ARIA live region，但定期倒计时不得造成频繁播报。

## 4. 非功能需求

- **NFR-001 浏览器**：首版支持当前及前一个主要版本的 Chrome、Edge、Firefox 和 Safari；移动浏览器需验证 iOS Safari 与 Android Chrome。
- **NFR-002 性能**：目录 API 在本地/同区域网络的目标响应时间为 300 ms 内；开始播放时间受媒体网络影响，界面必须立即反馈准备状态。
- **NFR-003 安全**：媒体路径只能来自已校验目录配置，API 不接受任意文件系统路径。
- **NFR-004 可维护性**：选择算法必须是无网络、无时钟副作用的纯逻辑，并有边界测试。
- **NFR-005 可观测性**：后端记录配置校验和媒体请求错误；不得记录不必要的客户端个人信息。
- **NFR-006 缓存**：配置响应支持版本/ETag；媒体可长缓存，但资源变更时 URL 或版本必须变化。
- **NFR-007 部署**：同源部署为默认，避免首版引入不必要的 CORS 和凭据复杂度。
- **NFR-008 隐私与隔离**：浏览器级设置只保存在当前站点的本地存储，不发送到后端；应用不得把它描述为账户或跨设备设置。

## 5. 待确认事项

以下内容在开始数据配置实现前必须解决：

1. 原项目在候选超过 6 种时是否还有 `auto_priority` 之外的取舍规则。首版基线采用 `04-data-and-api.md` 中的确定性规则。
2. 现有 MP4 的音频编码、时长、响度和浏览器兼容性；当前环境只有容器格式识别结果，没有 `ffprobe`。
3. 媒体资源的来源、版权和 Web 分发许可。
4. 生产运行在用户本机、局域网服务器还是公网服务器，以及对应的域名、HTTPS 和存储方式。
5. 是否需要全局音量、单轨音量、淡入淡出和静音等超出原说明的增强功能；首版暂不纳入。

旧版配置和研究已解决 17 种蝉的初始活动数据问题；其中 14 种允许自动播放，蟪蛄、黄蟪蛄和岩崎寒蝉因证据不足仅用于手动模式。数据依据和限制见 `08-cicada-research.md`。
