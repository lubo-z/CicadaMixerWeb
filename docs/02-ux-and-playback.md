# 交互与播放模型

## 1. 页面信息架构

首版使用单页布局，建议从上到下为：

1. 产品标题和“结果为氛围模拟”的简短说明；
2. 播放模式切换：手动混音 / 时节自动；
3. 自动模式参数区：时节、每日时段、自定义时间、自动混音上限、自动更新和检查间隔；
4. 蝉种列表；
5. 蝉鸣时段信息来源页脚；
6. 固定或易触达的播放 / 停止控制；
7. 状态与错误区域。

窄屏采用单列；宽屏可将参数和蝉种列表分栏。不能依赖 hover 才能读取资料：名称旁需要可聚焦的信息按钮，hover 只是桌面端快捷方式。

来源页脚复用 Catalog 的 `sources` 数据，按来源标题稳定排序并去重。链接显示来源标题，在新标签页打开，并使用安全的 `rel` 属性；固定播放器不能遮挡页脚内容。

## 2. 模式交互

### 手动混音

- 蝉种列表使用复选框。
- 候选选择和活动组合在状态上分离。
- “清空已选”只清空候选复选框；即使当前正在播放，也不得停止或改变活动组合。候选已为空时按钮禁用。
- 正在播放时修改复选框，界面应提示“选择已更改，点击播放以应用”，但不得切换声音。
- 点击播放：
  - 候选为空：保留现有活动组合并提示至少选择一种；
  - 候选非空：进入准备状态，成功加载的集合成为新活动组合。

### 时节自动

- 蝉种列表为只读结果，视觉上与禁用的手动复选框区分。
- 参数变化立即重算“预览组合”，但不得自动改动正在播放的活动组合；实时自动会话的定时检查除外。
- 自动混音上限以选择控件提供后端声明范围内的整数，默认 6；修改后立即重算预览，下一次播放或实时检查才应用到声音。
- 自定义时间仅在选择“自定义时间”时显示或启用。
- 非实时选项下隐藏或禁用自动更新，并说明自动更新仅适用于实时。
- 实时检查间隔以选择控件提供后端声明范围和步长内的分钟数，默认 30；自动会话中修改它只重排计时器，不中断声音。

### 浏览器级设置

- 自动混音上限和实时检查间隔保存在同源 `localStorage`，不提交给后端。
- 页面加载 Catalog 后再读取并校验设置；无效项恢复 Catalog 默认值。
- 控件只生成 Catalog 允许的值，界面可同时显示默认值和允许范围。
- 设置持久化失败时仍允许本次会话使用选择值；刷新后可能恢复默认值，不应阻断播放。

## 3. 播放状态机

主要状态如下：

| 状态 | 含义 | 允许的主要动作 |
| --- | --- | --- |
| `stopped` | 无活动声音、无自动会话 | 播放、修改参数 |
| `preparing` | 正在创建/加载新音轨 | 停止；参数可修改但不影响本次请求 |
| `playing` | 至少一个活动音轨正在播放 | 停止、再次播放、修改候选 |
| `waiting` | 自动会话存在，但当前无匹配项 | 停止；到检查点自动重算 |
| `partial_error` | 至少一轨成功、至少一轨失败 | 与 playing 相同 |
| `error` | 本次所有音轨失败 | 停止、修正后重试 |

所有异步播放操作携带递增的会话令牌。停止或开始新的播放请求会使旧令牌失效；旧请求稍后完成时不得重新开始声音。这用于避免快速连续点击产生“幽灵音轨”。

## 4. 组合替换

1. 冻结本次要应用的蝉种 ID 集合。
2. 创建新音轨并尝试加载/播放。
3. 至少一条新音轨成功后，停止旧组合，将成功集合设为活动组合。
4. 新组合全部失败时，停止准备中的新音轨；手动再次播放场景下保留旧组合继续播放，并显示失败。若不存在旧组合，则进入 `error`。
5. 停止操作始终清理全部新旧音轨、计时器和事件监听。

首版不承诺不同文件从同一采样点同步开始。若后续加入淡入淡出或 Web Audio 精确同步，必须先更新本文件和 ADR。

## 5. 浏览器播放约束

- 首次有声播放必须由用户点击触发，以满足浏览器自动播放政策。
- 自动会话中的后续切换复用已解锁的音频上下文；若浏览器仍阻止恢复，应进入错误状态并要求用户再次点击播放。
- 页面后台运行时，定时器和媒体可能被系统节流或暂停。恢复可见时执行一次即时校验。
- 页面刷新会终止播放和自动会话；首版不恢复播放状态。

## 6. 时间边界

- 所有计算基于浏览器本地时间。
- 区间采用左闭右开，避免边界时间同时匹配两个时段。
- 跨午夜区间满足 `time >= start OR time < end`。
- `24:00` 只允许作为配置区间的结束边界，不允许作为自定义时间输入。
- 夏令时跳变时，以页面当时取得的浏览器本地时间重新计算。
- 下一检查点按用户选择的分钟间隔与本地墙上时钟对齐，而不是简单地从当前时刻增加该间隔。

## 7. 状态文案示例

- 已停止
- 正在准备 4 条音轨……
- 正在播放 4 种蝉
- 正在播放 3 种蝉；“阳明山暮蝉”加载失败
- 当前没有匹配的蝉种，将于 10:30 再次检查
- 自动更新已开启；下一次检查：10:30
- 浏览器阻止了音频播放，请再次点击“播放”

错误详情应给用户可理解的名称；技术信息可写入开发日志，不在界面暴露服务器文件路径或堆栈。
