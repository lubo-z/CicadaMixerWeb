# 测试与验收

## 1. 测试层次

### 前端单元测试

- 月份集合与季节重叠；
- 普通、边界、跨午夜时间区间；
- 固定时段与鸣叫区间相交；
- 不同合法自动上限下的稳定排序；
- 不同合法间隔的下一对齐检查时间，包括跨日；
- 候选选择与活动组合分离；
- 浏览器设置缺失、合法、损坏、越界和步长不符时的读取与回退；
- 旧播放请求被会话令牌取消。

### 后端单元/集成测试

- 配置 schema 和所有交叉校验；
- 浏览器设置默认值、范围和步长约束的配置校验；
- Unicode 文件名和 media ID 解析；
- 目录不泄漏绝对路径；
- ETag / 304；
- 媒体完整响应、HEAD、206、416、404；
- 路径穿越和未知 ID 被拒绝；
- readiness 在无效配置时失败。

### 端到端测试

- 手动选择、播放、修改候选、清空候选且不中断播放、再次应用、停止；
- 调整自动混音上限、刷新后恢复设置、无效本地设置回退；
- 自动模式每个时节和每日时段；
- 自定义时间校验；
- 无匹配结果；
- 部分媒体请求失败；
- 自动更新组合不变/变化/空/恢复；
- 页面隐藏后恢复；
- 键盘操作和主要无障碍检查。

音频“真的发声”不能只靠 DOM 状态断言。自动化测试可用短小的测试媒体和播放器事件验证；发布前还需要人工听测。

## 2. 首版验收清单

### AC-01 手动混音

前置：目录至少有 3 个可用项目。

1. 选择 A、B 并播放。
2. 确认 A、B 循环且状态显示 2 种。
3. 取消 A、选择 C。
4. 确认声音仍为 A、B，界面提示尚未应用。
5. 再次播放，确认活动组合变为 B、C。
6. 播放期间点击“清空已选”，确认候选清空但活动组合继续播放。
7. 停止后所有声音终止。

对应：PR-MAN-001..007。

### AC-02 空的手动选择

未勾选任何项目点击播放，出现提示且现有活动组合不被意外停止。

对应：PR-MAN-005。

### AC-03 自动筛选

对已知测试配置分别选择当前月份、四季、固定时段和自定义时间，结果与 `04-data-and-api.md` 算法完全一致。分别选择上限 1、6、10，结果不超过所选值且稳定；活动组合只在播放或实时检查时更新。

对应：PR-AUTO-002..012。

### AC-04 时间边界

验证 04:59、05:00、07:29、07:30、11:59、12:00、16:29、16:30、18:59、19:00、23:59 和 00:00，每个时刻只按规定区间计算。

对应：PR-AUTO-006、PR-AUTO-007。

### AC-05 实时自动会话

用可控时钟启动实时自动更新：

1. 首次必须点击播放；
2. 默认 30 分钟时下一检查点对齐整点/半点；
3. 组合不变时播放器实例不中断；
4. 组合变化时替换；
5. 无匹配时进入 waiting；
6. 后续有匹配时恢复；
7. 会话中将间隔改为另一个合法值，声音不中断，下一检查点按新间隔重排；
8. 五类取消操作均清理计时器。

对应：PR-LIVE-001..010。

### AC-06 部分失败

选择 3 条媒体，让其中 1 条返回 404。其余 2 条继续播放，状态准确列出失败项；全部失败时不得显示“正在播放”。

对应：PR-MEDIA-003..005。

### AC-07 媒体传输

对每个生产媒体执行浏览器实际播放和 HTTP Range 检查。Safari、Firefox、Chrome 至少各完成一次完整人工兼容测试。

对应：PR-MEDIA-001、PR-MEDIA-006、NFR-001。

### AC-08 可配置性

只修改配置并重启后端，即可增加一个测试蝉种、调整时段和默认音量；不修改前端源码。

对应：PR-CAT-002..005。

### AC-09 可访问性

仅用键盘可完成模式切换、选择、参数输入、播放和停止；屏幕阅读器能获知关键状态；信息按钮可聚焦。

对应：PR-STATUS-002..003。

### AC-10 浏览器级设置

1. 首次访问时显示 Catalog 默认值 6 种和 30 分钟。
2. 改为其他合法值并刷新，当前浏览器恢复选择。
3. 确认没有写配置或用户设置的后端请求，另一浏览器上下文仍使用默认值。
4. 手工写入损坏、越界或不符合步长的本地值并刷新，逐项恢复默认值。
5. 后端收紧允许范围后，旧的越界本地值在下一次加载时恢复新默认值。

对应：PR-PREF-001..006、PR-CAT-006。

## 3. 发布门槛

- 所有需求有对应测试或书面人工验收步骤；
- 自动化测试通过，无跳过的关键路径测试；
- 17 个媒体完成格式、听感、循环和许可审计；
- 支持浏览器矩阵通过；
- 文档、OpenAPI、配置 schema 与实现一致；
- 没有已知的路径穿越、任意文件读取或脚本注入风险；
- 生产环境完成一次从空缓存加载和至少 60 分钟自动更新的稳定性测试。
