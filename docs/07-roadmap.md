# 实施路线图

本文件描述顺序，不代表授权立即开始编程。每个阶段开始前再次确认相关文档已被接受。

## Phase 0：资料与媒体基线

状态：部分完成。配置校验、名称映射和 Chromium 首条媒体解码已完成；完整媒体审计、版权和部署环境仍待确认。

- 校验 Web JSON 配置；
- 核实中文名与学名映射；
- 审计媒体编码、时长、响度、循环和版权；
- 确认技术栈与部署环境；
- 处理所有标为“待确认”的产品项。

完成定义：JSON 配置与 schema 校验完成，媒体审计与上线许可无空白项，当前 ADR 与实现一致。

## Phase 1：契约与纯逻辑

状态：已完成首版实现与自动化测试。

- 定义并校验配置 schema；
- 固化目录 API/OpenAPI；
- 实现并完整测试月份、时段和排序算法；
- 准备小型、可自由分发的测试媒体。

完成定义：选择逻辑边界测试和配置校验测试通过，契约与文档一致。

## Phase 2：后端与媒体分发

状态：已完成首版实现与自动化测试。

- 目录加载、API、健康检查；
- 安全 media ID 解析；
- Range、缓存和 Unicode 文件名；
- 配置错误的 readiness 和日志。

完成定义：后端集成测试通过，17 个媒体可被目标浏览器按范围请求。

## Phase 3：前端核心体验

状态：已完成首版实现；桌面与移动 Chromium 端到端测试通过。

- 页面和响应式布局；
- 手动/自动模式；
- 多轨循环播放器和默认音量；
- 状态机、容错、可访问性；
- 实时调度与页面可见性恢复。

完成定义：AC-01 至 AC-06 和 AC-09 通过。

## Phase 4：集成、兼容与发布

状态：进行中。单 Server 构建和 Chromium 验证已完成，其他目标浏览器及发布门槛尚未全部完成。

- 生产构建和同源部署；
- 浏览器与移动设备验证；
- 媒体听测、性能和长时间稳定性测试；
- 安全检查与运维说明；
- 最终核对文档和实现。

完成定义：`06-testing-and-acceptance.md` 的发布门槛全部满足。

## 后续候选功能

以下不属于首版，进入开发前必须先补充需求：

- 全局和单轨音量；
- 淡入淡出、随机偏移或空间声场；
- 保存和分享组合；
- PWA / 离线缓存；
- 地点、天气和海拔筛选；
- 可视化配置后台；
- 服务端转码和更多音频格式。
