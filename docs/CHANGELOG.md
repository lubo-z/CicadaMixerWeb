# 开发文档变更记录

所有影响需求、架构、接口、数据和验收的变化都记录在此。版本遵循语义化思路：破坏性基线变化增加主版本，兼容功能增加次版本，澄清和修正增加补丁版本。

## 0.6.0 - 2026-07-30

- 在页面页脚增加由 Catalog 数据生成的蝉鸣时段信息来源链接。
- 补充使用项目上级 `.venv` 和 `.node` 环境的激活、验证与恢复方法。
- 移除 README、运维文档和测试配置中的本机绝对路径，改为项目相对路径与已激活的工具环境。
- 删除失效 ADR，并移除一次性迁移说明和重复历史。
- 将媒体从项目根 `sounds/` 迁移至后端所有的 `backend/resources/sounds/`，并同步默认路径、测试和运维文档。
- 接受 ADR-0004：自动混音上限和实时检查间隔改为 `localStorage` 浏览器级设置，后端配置只提供默认值、范围和步长。
- 配置 schema 升级到 v2：`autoMix` 默认 6、范围 1–10；`liveRefresh` 默认 30 分钟、范围 5–120 分钟、步长 5 分钟。
- 增加手动模式“清空已选”，明确只清空候选、不影响活动声音。
- 补充设置校验、预览/活动组合边界、实时计时器重排和浏览器隔离验收标准。
- 将 JSON 配置及其 schema 从项目根 `config/` 移至后端所有的 `backend/config/`。
- 实现 FastAPI 配置加载、跨字段校验、Catalog、健康检查、安全媒体 ID、Range、缓存和前端静态分发。
- 实现 React + TypeScript 手动混音、自动筛选、实时更新、播放状态机、局部失败和响应式无障碍界面。
- 增加本地 Noto SC 字体，避免部署环境缺少中文字体或依赖第三方字体服务。
- 增加 pytest、Vitest、Testing Library 和 Playwright 桌面/移动 Chromium 测试。
- 增加项目运行说明、固定依赖和单 Server 生产构建流程。

## 0.3.0 - 2026-07-29

- 接受 ADR-0003：使用后端 `config.json` 和 JSON Schema，并通过安全的 Catalog API 提供前端数据。
- 完成 17 个蝉种、10 个来源和 5 个每日时段的配置校验。
- 明确媒体由后端管理和按 media ID 分发，浏览器负责实际混音。

## 0.1.0 - 2026-07-29

- 根据原 CicadaMixer 功能与使用说明建立 Web 版产品需求。
- 明确手动混音、时节自动、实时更新、错误降级和状态提示。
- 建立浏览器混音、FastAPI 只读后端的首版架构。
- 定义配置模型、确定性选择规则、HTTP API 和媒体 Range 契约。
- 建立 17 个现有媒体的名称映射和审计清单。
- 建立测试、验收、路线图、ADR 和文档先行流程。
